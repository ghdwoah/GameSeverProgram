## 시작하기

### 1. 학번부터 입력하세요

`Shared/StudentConfig.cs` 를 열어서 두 줄을 고칩니다.

```csharp
public static readonly int    STUDENT_ID   = 23230881;   // ← 본인 학번
public static readonly string STUDENT_NAME = "홍길동";    // ← 본인 이름
```

**안 고치면 프로그램이 실행되지 않습니다.**

포트는 학번에서 계산됩니다. 예를 들어 학번이 23230881이면
TCP 11004 · UDP 11005 를 쓰게 됩니다.

포트 번호가 학번에서 계산되므로, 여러분이 만드는 모든 로그와
측정 파일에는 본인 포트가 찍힙니다. 남의 결과를 그대로 낼 수 없습니다.

### 2. 실행

`TICKET-099.sln` 을 열고 세 프로젝트를 모두 실행합니다.

```
OutsourcedServer   ← 검토 대상 (서버)
TestClient         ← 검토 대상 (수동 테스트 클라이언트)
LoadTester         ← 검토 대상 아님 (측정 도구, 그대로 쓰세요)
```

여러 프로젝트를 동시에 실행하려면
솔루션 우클릭 → 속성 → 시작 프로젝트 → **여러 개의 시작 프로젝트**
에서 `OutsourcedServer` 와 쓰려는 도구를 "시작"으로 바꾸세요.

### TestClient 조작

```
W A S D  또는 방향키     이동 (UDP로 전송)
C                        채팅 보내기
R                        끊고 다시 접속
Q                        종료
```

화면 가운데 지도에서 `@` 가 나, `A` `B` `C` 는 다른 사람입니다.
키를 눌렀는데 아무 반응이 없으면 **한/영 키로 영문 입력 상태**인지 확인하세요.

### OutsourcedServer 파일

```
Program.cs         진입점
GameServer.cs      TCP 접속 받기, 세션 관리, 통계 출력
ClientSession.cs   접속자 1명 처리
PacketHelper.cs    TCP 패킷 송수신
Packets.cs         패킷 정의
UdpServer.cs       UDP 위치 동기화
```

## 서버 콘솔 읽는 법

서버는 2초마다 이런 줄을 찍습니다. **제출물에 이 줄을 캡처해서 넣으세요.**

```
[통계 23230881] t=  12s | 접속  32 | 스레드  41 | 가용워커  3 | UDP적용 1204 | 버림 0
```

| 칸 | 뜻 | 언제 보나 |
|---|---|---|
| `23230881` | 본인 학번 | 증거 캡처에 반드시 포함 |
| `t=12s` | 서버 가동 시간 | 재현 시각 대조용 |
| `접속 32` | 현재 접속자 수 | 부하 측정 중 |
| `스레드 41` | 현재 스레드 수 | Part B 핵심 지표 |
| `가용워커 3` | 스레드풀 여유 | 0 에 붙으면 신호 |
| `UDP적용 1204` | 위치를 실제로 갱신한 횟수 | 0 에서 안 오르면 신호 |
| `버림 0` | 오래된·중복이라 버린 패킷 | 기대값과 비교 |

## 주의

### 5주차 코드와 비교하세요

막지 않습니다. 권합니다. 실무에서 외주 코드를 받으면 제일 먼저 하는 일입니다.

다만 **다르다고 전부 문제인 건 아닙니다.**

주석을 빼고 코드만 세어도 쉰 군데 가까이 다릅니다. 그중 진짜 고칠 곳은
일부입니다. 일부러 더 낫게 바꿔 놓은 곳도 있습니다.

잘못 짚으면 건당 -3점입니다. 확신 없으면 쓰지 마세요.

### AI는 써도 되고 안 써도 됩니다

AI가 있어야 풀리는 문제는 하나도 없습니다. 점수와 무관합니다.

점수가 걸린 곳은 전부 "직접 돌려봤는가" 입니다.

- 본인 PC에서 나온 숫자
- 본인 포트가 찍힌 로그와 패킷 캡처
- 업체 주장을 실제로 돌려서 뒤집은 결과
- 막혔다가 풀린 과정

AI를 쓰든 안 쓰든 제출물은 똑같습니다.

### 고치지 말아야 할 것

`LoadTester` 는 측정 도구입니다. 여기를 고치면 측정값을 믿을 수 없게 됩니다.
